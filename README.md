# สร้าง QR Code

เว็บสร้าง QR Code แบบถาวร (ไม่มีวันหมดอายุ) จากลิงก์
ปรับสี QR ใส่ข้อความใต้ QR และบันทึกเป็นรูป PNG ได้ 3 ขนาด ไม่ต้องสมัคร ไม่ต้องใช้รหัส

## โครงสร้างไฟล์

```
index.html          หน้าเว็บ
assets/qrcode.js    ไลบรารีสร้าง QR (qrcode-generator 1.4.4, MIT License)
README.md           ไฟล์นี้
```

## อัปเดตเว็บบน GitHub

1. เปิด repo `qr-code` บน GitHub → **Add file → Upload files**
2. ลาก `index.html`, `README.md` และโฟลเดอร์ `assets` ขึ้นไปทับของเดิม → **Commit changes**
3. ถ้าใน repo ยังมีโฟลเดอร์ `pdf/` หรือ `apps-script/` จากเวอร์ชันก่อน ลบทิ้งได้
4. รอ 1–2 นาที แล้วกดรีเฟรชหน้าเว็บ (Ctrl+F5)

## วิธีใช้

1. วางลิงก์ เช่น Google Drive, Google Form หรือ YouTube
2. ใส่ข้อความใต้ QR (ไม่บังคับ) เช่น ชื่อเอกสาร
3. กด **บันทึกเป็น PNG**

**ทำ QR ให้ไฟล์ PDF:** อัปโหลด PDF ขึ้น Google Drive → คลิกขวา → **แชร์** → ตั้ง "การเข้าถึงทั่วไป" เป็น **ทุกคนที่มีลิงก์** → **คัดลอกลิงก์** แล้วนำมาวางในเว็บ
อยากแก้เนื้อหาโดยใช้ QR เดิม ให้คลิกขวาที่ไฟล์ใน Drive → **จัดการเวอร์ชัน** → อัปโหลดไฟล์ใหม่ ลิงก์และ QR จะเหมือนเดิม

QR ไม่มีวันหมดอายุ เพราะลิงก์ถูกเขียนลงในลาย QR โดยตรง QR จะใช้ได้ตราบเท่าที่ลิงก์ปลายทางยังเปิดได้
