# สร้าง QR Code

เว็บสร้าง QR Code แบบถาวร (ไม่มีวันหมดอายุ) จาก **ไฟล์ PDF** หรือจาก **ลิงก์**
ปรับสี QR และสีพื้นหลังได้ ใส่ชื่อไฟล์หรือข้อความใต้ QR และบันทึกเป็นรูป PNG ได้ 3 ขนาด

เว็บนี้เป็นไฟล์ HTML ธรรมดา ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล ใช้กับ GitHub Pages ได้ฟรี

## โครงสร้างไฟล์

```
index.html          หน้าเว็บหลัก
assets/qrcode.js    ไลบรารีสร้าง QR (qrcode-generator 1.4.4, MIT License)
pdf/                โฟลเดอร์เก็บไฟล์ PDF ที่ต้องการทำ QR
README.md           ไฟล์นี้
```

## วิธีติดตั้งบน GitHub Pages

1. สร้าง repository ใหม่บน GitHub ตั้งเป็น **Public** เช่นชื่อ `qr-code`
2. กด **Add file → Upload files** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ขึ้นไป (`index.html`, `assets`, `pdf`, `README.md`) แล้วกด **Commit changes**
3. ไปที่ **Settings → Pages**
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
4. รอ 1–2 นาที เว็บจะเปิดได้ที่
   `https://ชื่อผู้ใช้.github.io/qr-code/`

## วิธีทำ QR จากไฟล์ PDF

1. เปิดเว็บ ไปที่แท็บ **จากไฟล์ PDF**
2. กดปุ่ม **อัปโหลด PDF บน GitHub** (มุมขวาของรายการไฟล์) ระบบจะพาไปหน้าอัปโหลดเข้าโฟลเดอร์ `pdf/` โดยตรง
3. ลากไฟล์ PDF ขึ้นไป แล้วกด **Commit changes**
4. รอ 1–2 นาที กลับมาที่เว็บแล้วกด **โหลดรายการใหม่**
5. กด **สร้าง QR** ที่ไฟล์ที่ต้องการ ชื่อไฟล์จะขึ้นใต้ QR ให้อัตโนมัติ
6. กด **บันทึกเป็น PNG**

ถ้ามีไฟล์อยู่ในเครื่อง จะกด **เลือกไฟล์ PDF จากเครื่อง** ก็ได้ เว็บจะสร้างลิงก์ตามชื่อไฟล์นั้น และบอกว่าพบไฟล์บนเว็บไซต์แล้วหรือยัง

### ข้อแนะนำ

- **ตั้งชื่อไฟล์เป็นภาษาอังกฤษ ไม่มีเว้นวรรค** เช่น `course-2569.pdf` ลิงก์จะสั้นลง QR จะโปร่งและสแกนง่ายกว่าชื่อภาษาไทย (ข้อความใต้ QR แก้เป็นภาษาไทยได้ในช่อง "ข้อความใต้ QR")
- GitHub รับไฟล์ได้ไม่เกิน 25 MB ต่อไฟล์เมื่ออัปโหลดผ่านหน้าเว็บ
- ไฟล์ทุกไฟล์ใน repo แบบ Public **ทุกคนเปิดดูได้** อย่าใส่เอกสารที่มีข้อมูลส่วนตัว เช่น เลขบัตรประชาชน เบอร์โทร หรือที่อยู่

## QR ไม่มีวันหมดอายุจริงไหม

QR ที่เว็บนี้สร้างเป็นแบบคงที่ ลิงก์ถูกเขียนลงในลาย QR โดยตรง ไม่ผ่านบริการย่อลิงก์ จึงไม่มีวันหมดอายุ
QR จะยังเปิดได้ตราบเท่าที่

- repo ยังอยู่และยังเปิด GitHub Pages ไว้
- ไฟล์ PDF ยังอยู่ใน `pdf/` **ชื่อเดิม** (ถ้าเปลี่ยนชื่อหรือลบไฟล์ QR ที่พิมพ์ไปแล้วจะเปิดไม่ได้)
- ไม่เปลี่ยนชื่อ repo หรือชื่อผู้ใช้ GitHub

**อยากแก้เนื้อหา PDF โดยใช้ QR เดิม:** อัปโหลดไฟล์ใหม่ที่ **ชื่อเหมือนเดิมทุกตัวอักษร** ทับไฟล์เก่าในโฟลเดอร์ `pdf/` QR เดิมจะเปิดไฟล์ใหม่ทันที

## ใช้กับโดเมนของตัวเอง

ถ้าตั้ง Custom domain ให้ GitHub Pages เว็บจะหาชื่อ repo เองไม่ได้ ให้แก้บรรทัดนี้ใน `index.html`

```html
<meta name="qr-repo" content="ชื่อผู้ใช้/ชื่อrepo">
```
